# ACL Boost
A React Native app for structuring post-op ACL Recovery rehabilitation

## Features

- Personalized calendar with reminders for exercises
- 53 workout exercise library
- AI Generated advice for rehabilitation
- Workout Tracking with 15 performance metrics
